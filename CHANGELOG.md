# История версий Острова

Изменения сгруппированы по версиям, а не по дням разработки. Windows и Android развиваются независимо.

[Скачать тестовые версии](https://github.com/just-trust-digital/Ostrov.Browser/releases).

## Windows

Опубликованные сборки Windows являются предварительными. Записи 0.3.0–0.7.20 описывают исторические локальные сборки; установщики этих версий здесь не опубликованы. Все перечисленные Windows-сборки тестовые и без цифровой подписи.

### 0.7.27

- Панель вкладок и адресная строка занимают меньше места.
- Уменьшены всплывающие панели и убран дополнительный отступ у развёрнутого окна.
- Удалено уведомление о количестве открытых вкладок.
- Ошибка проверки расширения больше не мешает открывать страницы.

Перед установкой закройте Остров. Установщик не подписан. Windows может показать предупреждение SmartScreen: выберите «Подробнее», затем «Выполнить в любом случае».

### 0.7.25

[Скачать установщик](https://github.com/just-trust-digital/Ostrov.Browser/releases/download/v0.7.25/Ostrov-Setup-0.7.25.exe).

- Профили показаны плитками. Для нового профиля можно задать имя и выбрать изображение.
- В редакторе профиля доступны создание ярлыка и удаление профиля из списка с сохранением данных.
- Обновлены настройки рамки главного окна Windows 11 и их восстановление после полноэкранного режима.

Перед установкой закройте Остров. Установщик не имеет цифровой подписи.
Контрольные суммы находятся в SHA256SUMS.txt, исходный коммит и запуск сборки в BUILD.txt.

### 0.7.21

- Меню расширений заменено компактными плитками с короткими именами и контекстными командами.
- Добавлены создание профилей, цветные значки и отдельные ярлыки.
- Файлы одного экспорта сохраняются в общей подпапке; история загрузок сохраняет её после перезапуска.
- Стандартный установщик использует фирменное оформление Острова.


### 0.7.20

- Расширение для архивации чатов включено в поставку и доступно в отдельном профиле. В обычном профиле он не включается.
- Настройка панели инструментов оформлена плитками с обозначением показанных и скрытых кнопок.
- Исправлена подсветка выбранного раздела настроек.


### 0.7.19

- Импорт паролей Chrome/Edge из CSV: подтверждение, предпросмотр без показа паролей, пропуск дублей и атомарная запись.
- CSV передаётся из диалога выбора в памяти без дополнительной сохранённой копии.
- Выбор имени и формата при сохранении страницы: MHTML или HTML без дополнительных файлов; выбор имени PDF.
- Подтверждение закрытия вкладки или окна при незавершённых загрузках.
- Определение расширения поддержанных растровых изображений по содержимому; поиск выделенного текста через выбранный поисковик.

После импорта удалите исходный CSV: пароли в нём хранятся открытым текстом.

### 0.7.18

- Вместо надписи IP — значок островка с флажком.

- Ошибка определения страны не скрывает полученный IP.
- Фирменный мастер установки с песочным фоном и иллюстрацией Боцмана.

### 0.7.17

- Исправлено повторное открытие поискового запроса из истории.
- Новый профиль по умолчанию продолжает прежний сеанс.
- Подтверждения и ошибки приложения используют выбранные тему и язык.

## Android

### 0.8.0-dev3

Вкладки, избранное, история, загрузки, главная с каталогом сайтов и приватные вкладки на отдельных профилях WebView.

Android 8.0 и новее. Поддерживаются сертификаты НУЦ. Пакет подписан тестовым ключом.

Обновите Android System WebView. Для приватных вкладок необходима поддержка отдельных профилей и очистки данных в WebView. При отсутствии поддержки приватный режим не открывается.

Приватный режим экспериментальный: полное удаление данных просмотра пока не гарантируется. Камера, микрофон, расширения, прокси и автозаполнение паролей недоступны.
